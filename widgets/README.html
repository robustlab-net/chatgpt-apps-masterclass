4.3 배포 준비 — public/_headers

배포 전에 파일 하나만 추가하면, ChatGPT에서 위젯이 깨지지 않습니다.

왜 하나요? ChatGPT는 우리 위젯을 작은 창(iframe) 안에 띄웁니다. 그 창이 JS·CSS(assets/ 폴더)를 가져올 때, 서버가 “다른 사이트에서도 써도 된다”고 허락해야 합니다. 그게 Access-Control-Allow-Origin 헤더입니다. 없으면 화면이 하얗거나 깨져 보입니다.

ChatGPT → iframe → /index.html → /assets/*

public/_headers

/assets/*
    Access-Control-Allow-Origin: *

할 일

public/_headers 파일을 만들고 위 내용을 넣으세요. 빌드·배포하면 자동 적용됩니다.

💡참고

공개된 JS·CSS용 설정입니다. 로그인 API 같은 비밀 데이터에는 쓰지 마세요.

5 Move App 만들기

Move App은 MCP 서버(server) + 위젯(widgets)이 합쳐진 실제로 Claude / ChatGPT에 연결하는 앱입니다. 4강에서 만든 화면이 여기서 비로소 “채팅 안”에서 동작합니다.

4강과의 차이 4강: 브라우저·Ladle로 UI만 연습 (main.tsx, App.stories.tsx)
5강: server에 MCP 툴·위젯 리소스를 올리고 → Claude App · ChatGPT App에서 연결해 봄

Move App 구성 (한 줄 요약)

server MCP 툴 영화 툴 7개 + widgets 빌드 → Move App
  1. widgets에서 npm run build → server/dist
  2. server에서 영화 툴 7개 + registerAppResource (위젯 URI)
  3. server deploy → Workers URL 확보
  4. Claude App · ChatGPT App에 그 URL(MCP) 연결
  5. “개봉 예정 영화 알려줘” 등 → 툴 호출 → 위젯에 영화 데이터 표시

5강 진행 순서

Move App을 “완성”했다고 보려면, 두 환경(Claude / ChatGPT)에서 동일하게 동작해야 합니다. 로컬 Ladle만 예쁘다고 끝이 아닙니다.

5.1 Server Tools — registerAppTool

5.1에서는 server/src/index.ts에 영화 API 툴만 등록합니다. (create-deck 플래시카드 기능은 나중에 — 지금은 Movies App에 집중.) AI가 “언제 어떤 툴을 쓸지”는 description(한글)으로 알려줍니다.

registerAppTool이란? ChatGPT / Claude가 호출할 수 있는 기능(툴)을 서버에 등록하는 함수예요. _meta.ui.resourceUri가 있으면 결과를 위젯으로도 보여주고, 없으면 채팅 텍스트로만 돌아옵니다.

공통 패턴

server/src/index.ts — 패턴

registerAppTool(
  server,
  'get-upcoming-movies',
  {
    title: 'Get Upcoming Movies',
    description: '…한글로 언제 쓸지…',
    inputSchema: {},
    annotations: { readOnlyHint: true },
    _meta: {
      ui: { resourceUri: WIDGET_URI },
      'openai/toolInvocation/invoking': '불러오는 중…',
      'openai/toolInvocation/invoked': '완료.',
    },
  },
  async () => {
    // fetch movies from the api
    return { content: [{ type: 'text', text: '…' }] };
  },
);

7개 툴 description 전문 (복사용 · 한글)

get-upcoming-movies
사용자가 곧 개봉하거나 앞으로 나올 영화 목록을 보고 싶을 때 사용하세요. 현재 극장 상영작·스트리밍 작품에는 사용하지 마세요.

get-now-playing-movies
지금 극장에서 상영 중인 영화 목록을 보고 싶을 때 사용하세요. 스트리밍·개봉 예정 확인·특정 영화 검색에는 사용하지 마세요.

get-similar-movies
특정 영화와 비슷한 영화를 찾을 때 사용하세요. get-upcoming-movies 등으로 movieId를 먼저 얻으세요. 영화를 특정하기 전에는 사용하지 마세요.

get-movie-reviews
특정 영화의 리뷰를 보고 싶을 때 사용하세요. movieId가 필요합니다. 영화를 특정하기 전에는 사용하지 마세요.

get-movie-genres
장르 ID 목록이 필요할 때 사용하세요. get-movies-by-genre 전에 호출하세요. 영화를 직접 검색하는 용도는 아닙니다.

get-movies-by-genre
장르별 영화를 찾을 때 사용하세요. 먼저 get-movie-genres로 genreId를 확인하세요. (예: 28 액션, 99 다큐멘터리)

get-movie-details
줄거리·출연·제작사 등 특정 영화 상세를 볼 때 사용하세요. 목록 툴로 movieId를 얻은 뒤 사용하세요.

할 일

위 7개를 registerAppTool로 붙이고, async 안에 실제 API를 연결하세요. readOnlyHint: true는 조회 전용입니다.

예시 — 개봉 예정 영화 (description 한글)

get-upcoming-movies

    '현재 극장에서 상영 중인 영화나 스트리밍 가능한 작품에는 사용하지 마세요.',

5.2 API Fetcher — fetcher.ts

TMDB 호출은 server/src/fetcher.ts에 모읍니다. 5.1 툴에서는 fetchUpcomingMovies(env.API_KEY)처럼 함수만 부릅니다.

왜 분리하나요? URL·쿼리·에러 처리를 한곳에 두면 툴 7개가 짧아지고, TMDB 변경 시 수정이 쉽습니다.

할 일

  1. TMDB API 키(읽기 토큰) → server/.dev.vars의 API_KEY — Authorization: Bearer로 사용
  2. fetcher.ts 작성
  3. 각 툴 async에서 fetcher 함수 호출

함수 ↔ 툴

fetcher.ts — fetchFromTMDB

async function fetchFromTMDB(endpoint, apiKey, params = {}) {
  const searchParams = new URLSearchParams({
    page: '1',
    include_adult: 'false',
    language: 'en',
    ...params,
  });
  const response = await fetch(
    `https://api.themoviedb.org/3${endpoint}?${searchParams}`,
    { headers: { Authorization: `Bearer ${apiKey}` } },
  );
  if (!response.ok) throw new Error('Could not fetch from API');
  return response.json();
}

export async function fetchUpcomingMovies(apiKey) {
  return fetchFromTMDB('/movie/upcoming', apiKey);
}

registerAppTool에서 fetcher 연결

inputSchema에 넣은 필드는 핸들러 첫 인자로 구조 분해됩니다. 실제 배포 시 'x' 대신 env.API_KEY를 씁니다.

5.5 useApp Hook — React 위젯

server가 툴 결과를 내면, widgets의 React 화면이 그걸 받아야 합니다. 그 연결고리가 @modelcontextprotocol/ext-apps의 useApp입니다.

서버는 ext-apps/server, 위젯은 ext-apps/react를 씁니다. 같은 패키지인데 import 경로만 다릅니다.

1단계 — 패키지 설치

widgets 폴더에서 실행하세요. (시작하기에서 이미 했다면 생략)

npm i @modelcontextprotocol/ext-apps

2단계 — React에서 import

import { useApp } from "@modelcontextprotocol/ext-apps/react";
import역할
useApp 호스트와 위젯 연결 · ontoolresult로 툴 데이터 수신
LoadingIndicator 데이터 오기 전 로딩 UI
useState 툴 결과 toolOutput state

3단계 — 데이터가 흐르는 순서

server 툴 → structuredContent → ontoolresult → React state → 화면 UI

5.1·5.2에서 툴이 return { structuredContent: { movies: … } }처럼 돌려주면, 위젯의 app.ontoolresult 콜백에서 result.structuredContent를 꺼내 state에 넣습니다.

4단계 — App.tsx 전체 코드

src/App.tsx

import { useApp } from "@modelcontextprotocol/ext-apps/react";
import { LoadingIndicator } from "@openai/apps-sdk-ui/components/Indicator";
import { useState } from "react";

interface ToolOutput {
  movies?: Record<string, string>;
  movie?: Record<string, string>;
}

function App() {
  const [toolOutput, setToolOutput] = useState<ToolOutput | null>(null);

  useApp({
    appInfo: { name: "Movies Client", version: "1.0" },
    capabilities: {},
    onAppCreated: (app) => {
      app.ontoolresult = (result) => {
        if (result.structuredContent) {
          setToolOutput(result.structuredContent);
        }
      };
    },
  });

  if (toolOutput?.movies) {
    return <MoviesList movies={toolOutput.movies} />;
  }

  if (toolOutput?.movie) {
    return <MovieDetails movie={toolOutput.movie} />;
  }

  return (
    <div className="items-center justify-center flex min-h-50">
      <LoadingIndicator size={32} />
    </div>
  );
}

export default App;

5단계 — 코드 설명 (한 블록씩)

1 ToolOutput 타입

서버 structuredContent와 키 이름을 맞춥니다. 목록 툴(get-upcoming-movies 등)은 { movies: … }, 상세 툴(get-movie-details)은 { movie: … }를 돌려주므로 위젯도 movies / movie 두 가지를 구분합니다.

2 useState<ToolOutput | null>

처음엔 null(아직 툴 결과 없음) → 툴이 호출되면 setToolOutput으로 structuredContent 전체를 state에 넣습니다. 이 값으로 아래에서 어떤 화면을 그릴지 결정합니다.

3 useApp({ … })

옵션 3가지

  1. appInfo — 위젯 이름·버전 (호스트에 표시)
  2. capabilities — 지금은 {}. 나중에 기능 확장용
  3. onAppCreated — app이 준비된 뒤 ontoolresult 연결

onAppCreated의 app 인자만으로도 ontoolresult 연결은 가능합니다. 다만 5.7 Dark mode에서 useHostStyles를 쓰려면 const { app } = useApp(…)처럼 app을 꺼내 두세요.

4 app.ontoolresult

app.ontoolresult = (result) => {
  if (result.structuredContent) {
    setToolOutput(result.structuredContent);
  }
};

ChatGPT / Claude가 5.1 툴을 실행할 때마다 이 함수가 호출됩니다. result.structuredContent가 서버에서 넣은 { movies } 또는 { movie }예요.

5 조건부 렌더링 — 무엇을 보여줄까?

조건화면대응 툴 예시
toolOutput?.movies <MoviesList /> get-upcoming-movies, get-now-playing-movies …
toolOutput?.movie <MovieDetails /> get-movie-details
둘 다 없음 LoadingIndicator 툴 호출 전 · 로딩 중
movies 있음? → MoviesList | movie 있음? → MovieDetails | 아니면 로딩

MoviesList / MovieDetails는 별도 컴포넌트 파일로 만듭니다. App.tsx는 “데이터 받기 + 어떤 화면 쓸지 고르기”만 담당하는 게 깔끔합니다.

6단계 — 서버와 맞추기

5.1 툴에서 structuredContent: { movies: data.results }처럼 넣은 키 이름과 위젯 ToolOutput·if (toolOutput?.movies)가 같아야 목록이 뜹니다. 상세는 movie(단수)로 통일하세요.

5.7 Dark mode — useHostStyles

ChatGPT / Claude는 다크·라이트 테마를 씁니다. 위젯이 호스트와 다른 색이면 iframe 안에서만 어색하게 보입니다. useHostStyles가 호스트 테마 CSS를 위젯에 맞춥니다.

5.5에서 useApp만 썼다면, 여기서 import에 useHostStyles를 추가하고 app을 destructure 하면 됩니다.

1단계 — import 추가

import { useApp, useHostStyles } from "@modelcontextprotocol/ext-apps/react";
Hook역할
useApp 호스트 연결 · ontoolresult (5.5)
useHostStyles 호스트 다크/라이트·색상 토큰을 위젯 document에 적용

2단계 — app 받기 + useHostStyles 호출

useHostStyles는 첫 인자로 app 인스턴스가 필요합니다. 그래서 useApp 반환값을 destructure 합니다.

App.tsx — useApp 아래에 한 줄

const { app } = useApp({
  appInfo: { name: "Movies Client", version: "1.0" },
  capabilities: {},
  onAppCreated: (app) => {
    app.ontoolresult = (result) => {
      if (result.structuredContent) {
        setToolOutput(result.structuredContent);
      }
    };
  },
});

useHostStyles(app, app?.getHostContext());

1 useHostStyles(app, …) 인자

두 인자

  1. app — useApp이 만든 앱 인스턴스 (호스트와 연결된 객체)
  2. app?.getHostContext() — 호스트가 넘긴 테마·환경 정보 (없으면 undefined)

왜 getHostContext()를 넘기나요? ChatGPT가 다크 모드일 때 색 변수·color-scheme 같은 값이 여기 들어옵니다. useHostStyles가 그걸 읽어 위젯 <html> / document에 맞춥니다.

3단계 — Apps SDK UI와 함께

4.5에서 넣은 @openai/apps-sdk-ui 컴포넌트(LoadingIndicator, Button 등)는 호스트 테마 변수를 따릅니다. useHostStyles 없이 npm run dev만 하면 밝은 테마로만 보일 수 있습니다.

ChatGPT 다크 모드 → getHostContext() → useHostStyles → 위젯 + SDK UI

🧪 Ladle / dev

호스트 없음 → 테마 기본값. UI 레이아웃만 확인

💬 ChatGPT App

다크/라이트 전환 시 위젯 색이 채팅 앱과 같이 변함

4단계 — 전체 연결 예시

src/App.tsx (발췌)

import { useApp, useHostStyles } from "@modelcontextprotocol/ext-apps/react";

function App() {
  const { app } = useApp({ /* appInfo, onAppCreated … */ });

  useHostStyles(app, app?.getHostContext());

  // … toolOutput 조건 분기 · MoviesList / MovieDetails …
}
