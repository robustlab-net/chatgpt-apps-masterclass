4.3 Deployment Pipeline — public/_headers

강의 4.3에서 ChatGPT가 위젯을 iframe으로 띄울 때, Vite 빌드 결과인 assets/ 폴더 안의 JS·CSS·이미지 등을 cross-origin으로 불러옵니다. 이때 CORS 헤더가 없으면 리소스 로딩이 실패할 수 있어, Cloudflare _headers로 /assets/* 경로에 헤더를 붙입니다. 

/assets/*
    Access-Control-Allow-Origin: *

public/_headers는 배포 시 그대로 복사되며, 위 패턴에 맞는 모든 asset 응답에 Access-Control-Allow-Origin: *가 적용됩니다. 공개 정적 파일용 설정이며, 인증이 필요한 API에는 쓰지 않습니다.

4.4 Ladle — 컴포넌트 단독 개발

ChatGPT에 연결하지 않고 UI만 빠르게 보려면 Ladle을 씁니다. Storybook과 비슷하지만 가볍고, *.stories.tsx 파일만으로 스토리를 만듭니다.

설치

npm add @ladle/react

package.json에 스크립트 추가:

"ladle": "ladle serve"

실행: npm run ladle → 브라우저에서 스토리 목록 확인

Button.tsx — 컴포넌트와 props

버튼 UI와 받을 데이터 형태를 Button.tsx에 정의합니다. props 타입을 두면 Story에서도 같은 타입으로 맞출 수 있습니다. 

// src/Button.tsx
export interface ButtonProps {
  label: string;
}

export function Button({ label }: ButtonProps) {
  return (
    <button type="button" className="rounded-lg bg-black text-white px-4 py-2">
      {label}
    </button>
  );
}

Button.stories.tsx — Story와 args

Story<{}>(또는 Story<ButtonProps>)로 스토리를 선언하고, ButtonStory.args = { ... }에 넣은 값이 props로 전달됩니다. Ladle UI에서 args를 바꿔가며 상호작용할 수 있습니다. 

// src/Button.stories.tsx
import type { Story } from "@ladle/react";
import { Button, type ButtonProps } from "./Button";

export const ButtonStory: Story<ButtonProps> = (props) => <Button {...props} />;

ButtonStory.args = {
  label: "다음 카드",
};

데이터는 어디서 오나

환경 데이터 경로
ChatGPT 위젯 (App.tsx) app.ontoolresult → structuredContent → state → 컴포넌트 props
Ladle (*.stories.tsx) ButtonStory.args = { ... } → Story가 props로 전달

실서비스에서는 MCP 도구 결과가 ontoolresult로 들어오지만, Ladle에서는 ChatGPT 없이 Story args로 같은 props를 흉내 냅니다. 컴포넌트는 Button처럼 props만 받도록 두면 두 환경 모두에서 재사용하기 쉽습니다. 

// App.tsx (실제 위젯) — 요약
app.ontoolresult = (result) => {
  if (result.structuredContent) {
    setToolOutput(result.structuredContent);
  }
};
// toolOutput을 Button 등에 props로 넘김

// Button.stories.tsx (로컬) — 요약
ButtonStory.args = { label: "테스트" };

4.5 Tailwind + Apps SDK UI

Tailwind 4로 스타일을 잡고, @openai/apps-sdk-ui로 ChatGPT에 맞는 UI 컴포넌트를 씁니다. 강의 순서는 아래와 같습니다.

  1. Tailwind 패키지 설치
  2. vite.config.ts에서 tailwindcss import 후 plugins에 등록
  3. npm으로 @openai/apps-sdk-ui 설치
  4. App.css → index.css로 옮긴 뒤 App.css 삭제

1) Tailwind 설치

npm install tailwindcss @tailwindcss/vite

2) vite.config.ts — tailwindcss import

프로젝트 루트의 vite.config.ts를 열고, 상단에 import한 뒤 plugins 배열에 넣습니다.

import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig(({ mode }) => ({
  plugins: [react(), tailwindcss()],
  // base, build 등 기존 설정 유지
}));

이 프로젝트 실제 파일 예:

import tailwindcss from "@tailwindcss/vite";
// ...
plugins: [react(), tailwindcss()],

3) Apps SDK UI 설치 (npm)

npm install @openai/apps-sdk-ui

Tailwind 4가 먼저 붙어 있어야 SDK UI 스타일이 정상 동작합니다.

4) 전역 CSS — App.css → index.css

Vite 템플릿은 기본으로 src/App.css를 App.tsx에서 import 합니다. Tailwind·Apps SDK UI는 앱 전체에 한 번 넣는 전역 CSS가 맞으므로, 강의에서는 이렇게 정리합니다.

  1. App.css 내용을 복사해 index.css에 붙여 넣거나, index.css를 아래 내용으로 덮어씀
  2. src/App.css 파일 삭제
  3. App.tsx에 있던 import "./App.css" 제거 (있을 경우)
  4. main.tsx는 import "./index.css" 유지 — 컴포넌트 렌더 전에 로드

최종 index.css 예 (Tailwind + SDK UI):

@import "tailwindcss";
@import "@openai/apps-sdk-ui/css";
/* Required for Tailwind to find class references in Apps SDK UI components. */
@source "../node_modules/@openai/apps-sdk-ui";

/* The rest of your application CSS */

이 프로젝트에는 App.css가 없고 index.css만 있습니다. Ladle(App.stories.tsx)에서도 import "./index.css"로 같은 전역 스타일을 불러옵니다.

컴포넌트 import

경로별로 가져옵니다. 예:

import { LoadingIndicator } from "@openai/apps-sdk-ui/components/Indicator";
import { Button } from "@openai/apps-sdk-ui/components/Button";
import { Badge } from "@openai/apps-sdk-ui/components/Badge";

현재 App.tsx 예시

import { useApp, useHostStyles } from "@modelcontextprotocol/ext-apps/react";
import { LoadingIndicator } from "@openai/apps-sdk-ui/components/Indicator";

function App() {
  const { app } = useApp({ /* ... */ });
  useHostStyles(app, app?.getHostContext());

  return (
    <div className="flex min-h-50 items-center justify-center">
      <LoadingIndicator size={32} />
    </div>
  );
}

useHostStyles는 ChatGPT 호스트의 테마·색상 정보를 위젯에 맞춥니다. Apps SDK UI 토큰(bg-surface, text-secondary 등)이 호스트와 어울리게 쓰일 때 함께 사용합니다.

Ladle에서 확인

App.stories.tsx에 import "./index.css"가 있어야 SDK UI 스타일이 Ladle에도 적용됩니다. npm run ladle으로 LoadingIndicator 등을 ChatGPT 없이 미리 볼 수 있습니다.

선택: AppsSDKUIProvider

TextLink, ButtonLink 등에 라우터 링크를 쓸 때만 AppsSDKUIProvider로 감쌉니다. 단순 위젯만 만들면 생략 가능합니다.

문서·컴포넌트 목록: openai.github.io/apps-sdk-ui
