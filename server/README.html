Bindings & cf-typegen

wrangler.jsonc에 bindings(assets, KV 등)를 새로 추가하면 TypeScript는 타입에 반영된 것을 자동으로 알지 못합니다.

  1. wrangler dev를 종료
  2. npm run cf-typegen 실행 (wrangler types)

그러면 TypeScript도 바인딩을 인식합니다. 예: assets → env.ASSETS

환경 변수 (.dev.vars)

.dev.vars에 변수를 추가한 뒤에도 npm run cf-typegen을 실행하면 env 타입에서 확인할 수 있습니다.

KV remote: true

wrangler dev 중에도 로컬 KV 에뮬레이터 대신 실제 Cloudflare KV(원격)에 읽고 씁니다. 로컬 임시 저장 없이 실제 데이터를 확인할 때 유용합니다.

4.3 Deployment Pipeline

server 폴더에서 npm run deploy를 실행하면 npm lifecycle에 따라 아래 순서로 진행됩니다.

1. predeploy ../widgets로 이동 후 npm run build
→
2. deploy wrangler deploy

package.json의 predeploy는 JSON이라 주석을 달 수 없어 이 문서에 정리합니다. widgets 빌드 결과는 dist에 모이고, Worker의 ASSETS 바인딩으로 서빙됩니다.

cd server
npm run deploy
